# Client Lead Management System (Mini CRM)

## Project Overview

Mini CRM is a full-stack web application developed to manage client leads generated from website contact forms. The system allows administrators to track leads, update their status, add notes, and manage customer interactions efficiently.

## Features Implemented

* Add New Lead
* Admin Login Authentication
* Admin Dashboard
* Lead Listing (Name, Email, Source, Status)
* Lead Status Updates (New, Contacted, Converted)
* Notes and Follow-ups Management
* Delete Lead Functionality
* Responsive User Interface

## Technologies Used

### Frontend

* React.js
* CSS
* React Router DOM
* Axios

### Backend

* Node.js
